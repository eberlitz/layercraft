# Clean-Room & Independence Disclaimer

LayerCraft is an independent project and is not affiliated with, endorsed by, derived from, or connected to OrcaSlicer, PrusaSlicer, Bambu Studio, SuperSlicer, UltiMaker Cura / CuraEngine, or Slic3r.

LayerCraft is developed under a strict clean-room policy:
- Contributors and AI agents do **not** read, copy, translate, link, or decompile GPL, LGPL, or AGPL slicer source code or binaries.
- Implementation algorithms come solely from public file format specifications (STL, 3MF, G-code), peer-reviewed geometric literature, and first-principles engineering.
- External slicers (such as an installed `OrcaSlicer` CLI in `tools/orca-oracle/`) are run strictly out-of-process as black-box behavioral and physical-statistics oracles on public test meshes.
