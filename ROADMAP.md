# LayerCraft Roadmap

- **Phase 0 — Governance, Clean-Room Harness & Oracle (Done):** Workspace crates, `cargo xtask` checks (`layers`, `licences`, `wasm`, `fast`, `oracle`, `ladder`), `AGENTS.md`, skills, G-code physical invariant evaluator, analytic + black-box `OrcaSlicer 2.5.2` oracle harness.
- **Phase 1 — Tier 01 Slice MVP (Done):** Exact Z-plane mesh slicing, classic perimeter offsetting, top/bottom solid skin detection, rectilinear & grid infill, Klipper/Marlin G-code emission, STL & 3MF input, `layercraft-cli`.
- **Phase 2 — Engine Extensions, MCP Server, 3D Viewport & Web App (Done):** `layercraft-viewport` (camera + headless PNG renderer), `layercraft-viewport-gpu` (`wgpu`), `layercraft-ui-egui` (Prepare/Preview UI + layer scrubber), `layercraft-mcp` (JSON-RPC 2.0 + PNG screenshots), `layercraft` desktop app, `layercraft-web` WASM target.
- **Phase 3 — Print-Quality & Profile Parity:**
  - **Phase 3A — Real-Printer G-code Essentials (Done):** Custom start/end/layer-change G-code macro templates, part-cooling fan (`M106`/`M107`) + min-layer-time cooling slowdown, volumetric flow capping (`mm^3/s`), seam placement (`aligned`, `back`, `nearest`, `random`), wipe-on-retract, Z-hop, first-layer temperatures & per-role speed overrides, Complexity Ladder Tier 02 (`02-print-quality`).
  - **Phase 3B — Bridges, Overhangs & Richer Infill (Done):** Bridge island anchoring & optimal bridge direction, overhang wall detection & slowdown (`overhang_threshold_deg`), `Bridge` / `OverhangWall` fan boost & flow ratio, Gyroid & Cubic 3D sparse infill patterns, monotonic top/bottom solid fill, Complexity Ladder Tier 03 (`03-bridges-overhangs-infill`).
  - **Phase 3C — Supports & Multi-Object Plates (Done):** Grid & Snug automatic supports with top/bottom Z gaps, XY model clearance, dense `SupportInterface` layers, `on_build_plate_only` reachability filtering, `ObjectTransform` (scale/rotate/place), FFDH multi-object auto-arrange (`plate.*` engine commands + UI panel), Complexity Ladder Tier 04 (`04-supports-multi-object`).
  - **Phase 3D — JSON Profile Inheritance & Presets (Done):** Clean-room OrcaSlicer/Bambu JSON profile inheritance loader (`ProfileLibrary`, `machine_model` fallback, percentage line widths/speeds, bed plate selection, filament overrides, diagnostic warnings/unmapped keys), built-in LayerCraft starter presets, Orca/Bambu G-code template placeholder aliases, `profile.*` engine commands, CLI & UI integration, Complexity Ladder Tier 05 (`05-profiles`).
  - **Phase 3E — Printer-Readiness Pass (Done):** `GcodeFlavor::MarlinBuddy`, Pressure Advance (`SET_PRESSURE_ADVANCE` / `M572` / `M900`), per-role acceleration (`SET_VELOCITY_LIMIT` / `M204`), active chamber temperature (`M141`/`M191`), `M73` print progress, safe `{if}/{elsif}/{else}/{endif}` and arithmetic `{expr}` G-code template evaluator with print bounding box variables, 0.2 mm HF nozzle & Prusa CORE One+ starter presets, Start/End G-code editor & browser WASM G-code download UI, Complexity Ladder Tier 06 (`06-printer-readiness`).
- **Phase 4 — Advanced Slicing Capabilities:**
  - **Phase 4A — Surface & Motion Finish (Done):** Top-surface low-flow monotonic ironing (`Off`, `TopmostSurface`, `AllTopSurfaces`), outer-wall Z/E-ramped scarf seams (`Subdivide + Phase A/B/C overlap`), greedy circumcircle `G2`/`G3` arc fitting + `evaluate_gcode` arc/scarf physical invariant checks, JSON profile mappings, UI controls, Complexity Ladder Tier 07 (`07-surface-motion-finish`).
  - **Phase 4B — Variable-Width Walls (Medial-Axis / Arachne) (Done):** Segment Voronoi medial-axis extraction in `layercraft-clip` (`boostvoronoi` + WASM `getrandom` `wasm_js`), variable-width `ExtrusionPath` & bead width distribution solver (`layercraft-slice`), per-segment variable-width extrusion & `wall_width_variation_ratio` evaluator (`layercraft-gcode`), tapered 3D/2D viewport ribbons, JSON Arachne profile mappings, UI controls, Complexity Ladder Tier 08 (`08-variable-width-walls`).
  - **Phase 4C — Tree / Organic Supports (Done):** Branching model-avoiding support trees from overhang tips to the build plate (`TreeSupportConfig`, reachability cone avoidance, organic branch attraction/merging, hollow multi-wall circular trunks with base flare & dense interface caps, `tree_support_*` JSON profile keys, UI controls, Complexity Ladder Tier 09).
  - **Phase 4D — Variable Layer Height & Modifier Volumes (Done):** Curvature-driven adaptive Z scheduling (`AdaptiveLayerConfig`, slope-based height targets, Gaussian smoothing, step-ratio & top-cap remainder lookahead), explicit Z `HeightRangeModifier` bands, physical `top_shell_thickness_mm` / `bottom_shell_thickness_mm`, physical-Z support clearances, 3D modifier primitives & meshes (`Modifier`, `SupportBlocker`, `SupportEnforcer`) with disjoint region partitioning, JSON adaptive/shell profile keys, `plate.*modifier*` engine commands, `ColorMode::LayerHeight` & translucent modifier viewport rendering, Variable Layer Height + Modifier Volumes UI controls, `evaluate_gcode` layer-height variation metrics, Complexity Ladder Tier 10 (`10-variable-layer-modifiers`).
  - **Phase 4E — Multi-Material & Wipe/Prime Tower (Deferred):** Multi-tool assignments, tool-change macros, and purge/prime tower generation.
- **Phase 5 — Studio UI, Real-Print Quality, AI Agent MCP & Workflow:**
  - **Phase 5A — Studio UI & 3D Viewport Redesign (Done):**
    - *Pass 1:* Modular `layercraft-ui-egui` (`theme`, `icons`, `ui_kit`, `toolbar`, `sidebar`, `viewport_hud`), Dark Studio / Light Drafting / System theme engine with LayerCraft Cool Precision Teal accent, custom HiDPI `Painter` vector icons, two-tier header + collapsible contextual ribbon, native desktop Open/Save file pickers (`rfd`), drag-and-drop overlay, sticky Preset Card + tabbed Plate Outliner & Settings sidebar, floating interactive 3D ViewCube gizmo, floating vertical layer scrubber, and floating Preview summary/legend HUD.
    - *Pass 2:* 4× MSAA offscreen rendering, theme-aware studio gradient backdrop, physical matte build plate with major/minor grid & front teal indicator, crease-angle smooth mesh vertex normals, 3-point specular/Fresnel rim shader, and selection highlight tint.
  - **Phase 5B — Real-Printer Polish & Dimensional/Travel Quality (Done):** Prusa CORE One+ HF 0.4 mm preset suite, elephant-foot compensation, XY contour & hole compensation, wall ordering (`Inner/Outer`, `Outer/Inner`, `Inner/Outer/Inner`), concentric top/bottom patterns, nearest-neighbor island ordering & combing (avoid crossing perimeters), embedded G-code PNG thumbnails (`; thumbnail begin`), Phase 5B JSON profile mappings & Studio sidebar controls, Complexity Ladder Tier 11 (`11-real-printer-polish`).
  - **Phase 5C — AI Agent & MCP Power-Up (Done):** Live desktop Studio bridge (`layercraft-cli mcp --connect` / `auto` / `--standalone` over local IPC + `MCP Live` status indicator in `layercraft`), Printability / DFM diagnostics (`plate.analyze_printability`: overhang risk, floating islands, thin-wall checks, bridge spans, bed contact area, and per-feature filament/time breakdown), token-efficient MCP ergonomics (`list_commands`, `describe_command`, atomic `batch`, `config.patch`, `gcode.save_file` with built-in evaluation, `slice.compare` / `compare_screenshot` 3-panel A/B diffing, `set_view`, live `camera: "current"` screenshots), MCP resources, and bundled `skills/layercraft/SKILL.md` (`skill_reference`).
  - **Phase 5D — CORE One+ First-Print Readiness & Preview Scrubber (Done):** Hardened Prusa CORE One+ 0.2/0.4 mm HF start/end G-code (`M17`, `M862.1 A0`, `M862.5 P2`, `G29 P9` nozzle clean, `Y=-2.5` front-edge purge line + post-purge Z travel clearance, PLA chamber exhaust control `M106 P3`, ergonomic bed drop), internal same-island infill retraction/Z-hop suppression (`reduce_infill_retraction`), per-filament `flow_ratio`, pure-Rust QOI xLCD thumbnails (`; thumbnail_QOI begin`) + Buddy footer metadata comments, travel-move preview & horizontal intra-layer move scrubber with live 3D nozzle marker, and clean-room `tools/orca-oracle/compare_model.py` black-box OrcaSlicer comparison tool.
  - **Phase 5E — Full `.3mf` Loading, Project Persistence & Session Workflow (Done):** Full multi-part & multi-plate `.3mf` import (`_rels/.rels` root discovery, `<build><item transform>` 4×3 row-vector affine matrices, Production Extension `p:path` external `3D/Objects/*.model` component references, `Metadata/model_settings.config` plate assignments/names, negative-determinant winding preservation, per-plate relative layout), LayerCraft multi-plate `.3mf` project persistence (`project.save_file` / `project.load_file` / `plates.*` commands / WASM download & drop storing plates, objects, transforms, modifiers, active profiles, and `PrintConfig`), bounded engine undo/redo history (`session.undo` / `session.redo` / `session.history`, UI buttons + `Ctrl+Z`/`Ctrl+Shift+Z`/`Ctrl+S`, drag & atomic batch coalescing), async background slicing in desktop Studio, 3D click-to-select picking (`OrbitCamera::screen_ray` + `ray_intersect_mesh`), GPU-instanced rounded bead rendering & chunked `wgpu::Buffer` uploads, and responsive narrow-viewport chrome polish.
  - **Phase 5F — Direct Printer Upload & Binary G-code (Done):** Clean-room Prusa Binary G-code (`.bgcode` v1: `GCDE` magic, `Heatshrink 11_4`/`12_4` + `Deflate`/`None`, CRC32 block checksums, PNG/QOI thumbnail blocks, INI metadata), direct LAN upload client (`layercraft-io`: `PrusaLink` with RFC 2617/7616 HTTP Digest + `X-Api-Key`, `Prusa Connect Local`, `OctoPrint`, `Moonraker`, `0o600` local `printers.json` store kept out of `.3mf` files), `gcode.export_bgcode` / `printer.*` engine commands, `printer_status` / `upload_to_printer` MCP tools & `layercraft://printers` resource, Studio Machine printer card + non-blocking Send to Printer dialog + browser `.bgcode` download, and `layercraft-cli slice --binary` / `eval` / `printer {test, upload}`.
  - **Phase 5G — High-Poly Performance (Done):** Z-interval triangle bucketing & 5 µm contour simplification (`layercraft-mesh`), AABB disjoint-island clustering (`layercraft-clip`), Y-slab spatial `MaskClipIndex` for `O(1)` overhang splitting & fast rotated scanline hatching (`layercraft-slice`), and native zero-dep `std::thread::scope` multi-threaded per-layer slicing (staying bit-for-bit deterministic and `wasm32`-clean).
  - **Phase 5H (Next) — Mesh Prep & Repair:** Lay-flat-on-face, planar cut/split, OBJ import, basic non-manifold STL repair.
